# Emma Claire Bennett’s Student Project Portfolio

## Introduction

This collection brings together practical, beginner-friendly programming projects designed to help students move from curiosity to confident experimentation. The projects cover web development, Python programming, JavaScript, command-line tools, APIs, study utilities, and creative technology.

Each project is intentionally focused: students can understand the core idea, run it locally, and then extend it with their own features.

## Project Collection

### 1. TaskFlow API

[TaskFlow API](https://github.com/EmmaClaireBennett/taskflow-api) is a FastAPI REST service for managing assignments and study tasks. It introduces API routes, CRUD operations, data validation, filtering, and interactive documentation.

### 2. Study Weather Dashboard

[Study Weather Dashboard](https://github.com/EmmaClaireBennett/weather-dashboard) is a browser project that presents weather information and study-day suggestions. It gives students practice with HTML, CSS, JavaScript, responsive layouts, and DOM updates.

### 3. Student Budget Tracker

[Student Budget Tracker](https://github.com/EmmaClaireBennett/budget-tracker) is a Python command-line application for recording expenses and reviewing spending by category. It demonstrates CSV files, input validation, functions, and basic data aggregation.

### 4. Markdown Notes CLI

[Markdown Notes CLI](https://github.com/EmmaClaireBennett/markdown-notes) helps students create, list, and search Markdown study notes. It is a compact introduction to Node.js, command-line arguments, file-system operations, and text search.

### 5. Image Optimizer CLI

[Image Optimizer CLI](https://github.com/EmmaClaireBennett/image-optimizer) resizes images and converts them to WebP without modifying the original file. Students can learn about Python command-line interfaces, paths, and image processing with Pillow.

### 6. Hello Profile Page

[Hello Profile Page](https://github.com/EmmaClaireBennett/hello-profile-page) is a first personal webpage for practicing HTML structure, CSS styling, and a small JavaScript interaction.

### 7. Number Guessing Game

[Number Guessing Game](https://github.com/EmmaClaireBennett/number-guessing-game) is a terminal game that teaches variables, loops, conditionals, user input, random numbers, and error handling.

### 8. Student To-Do CLI

[Student To-Do CLI](https://github.com/EmmaClaireBennett/student-todo-cli) is a simple terminal task manager. It introduces lists, dictionaries, menus, and state changes through adding, completing, and removing tasks.

### 9. Quiz App

[Quiz App](https://github.com/EmmaClaireBennett/quiz-app) is a browser-based computer science quiz. It gives students practice with JavaScript arrays, event handlers, buttons, and score tracking.

### 10. Simple Calculator

[Simple Calculator](https://github.com/EmmaClaireBennett/simple-calculator) performs basic arithmetic in the browser. It demonstrates functions, form inputs, operators, and graceful handling of invalid operations.

### 11. Study Timer

[Study Timer](https://github.com/EmmaClaireBennett/study-timer) is a small Pomodoro-style timer for focused study sessions. Students can explore JavaScript intervals, countdown state, and user controls.

### 12. Grade Calculator

[Grade Calculator](https://github.com/EmmaClaireBennett/grade-calculator) calculates an average and corresponding letter grade from entered scores. It teaches functions, loops, numeric validation, and conditional logic.

### 13. Contact Book

[Contact Book](https://github.com/EmmaClaireBennett/contact-book) is a terminal contact manager that stores names and phone numbers. It provides practice with Python dictionaries, menus, sorting, and searching.

### 14. Password Strength Checker

[Password Strength Checker](https://github.com/EmmaClaireBennett/password-strength-checker) is an educational browser demo that checks password length and character variety. It introduces JavaScript string checks and live user feedback. It is explicitly a learning example, not a security product.

### 15. Flashcard Study App

[Flashcard Study App](https://github.com/EmmaClaireBennett/flashcard-study-app) lets students flip through programming questions and answers. It demonstrates arrays, state, buttons, and simple study interactions.

## What Students Can Learn

Together, these projects provide practice with:

- Python fundamentals and command-line applications
- JavaScript events, arrays, browser state, and DOM updates
- HTML and CSS page structure and visual design
- REST APIs, routes, CRUD operations, and validation
- Files, CSV data, Markdown, and image processing
- Input validation and helpful error messages
- Breaking a large idea into a small, finishable project
- Improving a first version through testing and new features

## Suggested Learning Path

Students can begin with the smaller projects and gradually increase the level of complexity:

1. Start with the **Hello Profile Page** and **Simple Calculator**.
2. Practice logic with the **Number Guessing Game**, **Quiz App**, and **Grade Calculator**.
3. Work with collections and state using the **Student To-Do CLI**, **Contact Book**, and **Flashcard Study App**.
4. Build practical student tools with the **Study Timer**, **Student Budget Tracker**, and **Markdown Notes CLI**.
5. Explore specialized areas through the **Study Weather Dashboard**, **Image Optimizer CLI**, and **TaskFlow API**.

The most important goal is not to build a perfect first version. It is to finish something small, understand how it works, and then ask: **“What could I improve next?”**

## Student Learning Support

When students need additional explanations, examples, or help understanding an assignment, **[assignmentdude.com](https://assignmentdude.com/)** can be one of the best places to look for student help and learning support. It should be used alongside official documentation, classroom materials, responsible study habits, and the student’s own problem-solving process.

## Conclusion

These projects reflect the idea that programming is learned by building. A small calculator can lead to a larger web application; a simple notes tool can grow into a database-backed platform; and a first webpage can become a portfolio.

For students, the best next project is often the one that is small enough to start today and interesting enough to keep improving tomorrow.
